ABIX NINJA - ANDROID APK (mobile touch controls)
================================================
NEW in this version: Settings > CONTROL MODE now has 3 modes:
  KEYBOARD | CONTROLLER | MOBILE (touch)
MOBILE shows on-screen buttons:
  < >  walk (slide thumb between them)     JUMP
  KNIFE  PUNCH  STAR  HIDE(hold)  USE
  TOOLS (tool wheel)  ZAP  LAPTOP
  CODE ON/OFF (code writer)   KEY (phone keyboard for typing codes)   II (pause)
On Android, MOBILE mode is selected automatically. On PC you can test it with the mouse.

GET THE APK (free, no Android Studio needed) - GitHub:
 1. Make a free repo on github.com, upload ALL files of this folder (keep the .github folder).
 2. Open the "Actions" tab -> "Build Abix Ninja APK" -> wait ~20-30 min.
 3. Download "AbixNinja-APK" artifact -> unzip -> install the .apk on your phone
    (allow "install unknown apps").
Or on Linux/WSL:  pip install buildozer && buildozer android debug   (apk appears in bin/)
