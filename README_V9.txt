ABIX NINJA - v9 UPDATE
======================

1. ABIX STORE  (laptop / Gaming PC e notun app)
   - Desktop, Start menu ba Taskbar theke "Abix Store" kholo.
   - CALCULATOR ar NODEPAD  ->  [Download] chapo. Download shesh hole app Desktop / Start / Taskbar e chole ashe.
   - Save file e thake: ekbar download korle abar korte hobe na.

2. CALCULATOR
   - Mouse click, ba keyboard: 0-9  + - * /  ( )  .   Enter = result,  Backspace = mushe,  C = clear.

3. NODEPAD
   - "+ Node" = notun note-node.   Node er upor click kore type koro.   Drag kore sajao.
   - "Link" chalu kore duto node click korle jora lage (abar click = link muche).
   - "Delete" = selected node muche,  "Clear" = shob muche.

4. TERMINAL + LAPTOP (notun niyom)
   - L chaple laptop khole jekhane khushi. KINTU terminal unlock korte hole terminal er SHAMNE jete hobe.
   - Terminal theke dure: Python e "unlock all" likhle kichu hobe na  ->  "ERROR: no terminal found".
     WIRE CONNECT puro korleo  "no terminal found".
   - Terminal er shamne L chaple: 3D animation - USB stick ashe, terminal er port e lage,
     LED sobuj hoy, tarpor laptop on hoy (3D dhakna khola). Tarpor WIRE CONNECT / Python e unlock.

5. WIRE CUTTER (key 0)
   - Ekhon Level 3, 4, 5, 6, 8, 9 e kaj kore.
   - Level 4 = GREEN wire,  Level 6 = RED wire,  Level 8 = BLUE wire.
     Ei 3 level e 3 ta tar thake. Level er rong er tar ta MAIN LINE - seta shobar SHESH e katte hobe.
     Baki duto age (jekono order). Bhul tar = short circuit, abar shuru.
   - Level 3, 5, 9: ager moto (note e lekha order e tar kato).
   - Level 6 e notun DOCK POWER BOX (x=5350): cut korle 12 second snipers/camera bondho.
